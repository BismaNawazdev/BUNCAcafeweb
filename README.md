# BUNCAcafeweb
BUNCA Human & Roaster — City café A one-page, vanilla HTML/CSS/JavaScript website for BUNCA's Frankfurt City café. The visual direction is neighborhood editorial: deep roastery green, toasted apricot, unbleached-paper tones, confident serif headlines, and small mono-style wayfinding details. It is designed to feel generous and personal rather than like a generic café directory.  The four site files index.html — semantic page content, SEO/Open Graph metadata, and the Vite entry point. src/styles.css — responsive visual system, layout, focus and motion states. src/main.js — mobile navigation and progressive scroll reveals. DOCUMENTATION.md — source and editing notes. The hero image is an additional supplied static asset at public/images/bunca-cafe-hero.jpg. It is an illustrative café-ambience image, not a photograph of a real BUNCA location. The compact public/favicon.svg is a site icon, and the fixed WhatsApp button links directly to the supplied phone number.  Run it Use the existing workspace workflow for the BUNCA Café Website artifact (the Vite dev workflow). Alternatively, from the project root run pnpm --filter @workspace/bunca-cafe-site run dev. The project uses Vite to serve the vanilla entry file; no React UI, backend, or data API is required. The existing package manifest and Vite config are scaffold infrastructure, not site content.  Content and sources The official web links are https://bunca.de/ and https://buncacoffee.com/ (the latter redirects to the former). Both are included. The City café address is the user-supplied Kirchnerstraße 4, 60311 Frankfurt am Main, Germany. The map and directions link use this address specifically; no other BUNCA location is implied. Contact details supplied for this location: +49 69 85003577, tel:+496985003577, and WhatsApp https://wa.me/496985003577. “4.6 · 1,216 reviews” is a historical snapshot from the user-provided listing at capture time, not a current live rating. It is labelled as listing snapshot data in the page. No reliable opening hours were supplied, so the page makes no hours claim. No social-media handles were supplied. No social links are invented; only official websites and WhatsApp are linked. Coffee, own roastery, in-house bakery, pastries, banana bread, and pastel de nata are drawn from the supplied brand/listing brief. Menu items are descriptive highlights, not a complete menu or price list. The meaning of BUNCA refers to the supplied Tigrinya expression “bun’n ka,” roughly “here is your coffee.” Editing Contact details and external links are in index.html: update the address in the visit section and its encoded Google Maps query, the tel: number, WhatsApp URL, and the official website anchors together. The historic rating and its source note are adjacent in that same section. Navigation destinations are in-page anchors; if a section ID changes, update its matching navigation link. Replace the illustrative image at public/images/bunca-cafe-hero.jpg to change the hero artwork, and keep its alt text accurate. Update metadata in the document head when changing the site name or summary.  When deploying this as BUNCA’s official site, set the canonical URL and an absolute Open Graph image URL to the confirmed public domain.  No external API is used. The embedded map is a Google Maps directions embed URL for the provided address; it does not supply business hours or live café data.
